# Aurelle Studio

A premium salon website concept by **Codingo Forge**.

## Features
- Responsive editorial layout in plum, peach, and ivory
- Six services with category filters
- Three-step demo appointment flow: service, visit details, review
- Missing-selection validation and on-screen confirmation
- Keyboard-friendly native dialog and reduced-motion support

## Run locally
```sh
python3 -m http.server 8080
```
Then open http://localhost:8080. No package installation or build is needed.

## Stack
HTML, CSS and vanilla JavaScript. Italiana and DM Sans via Google Fonts. Built with AI assistance through Codex.

## Demo scope
This is a self-initiated portfolio concept, not a client project. No appointments are reserved, payments collected, or notifications sent. Names, services, prices, and availability are sample content. The site has no backend or persistent booking database.
